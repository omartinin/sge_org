# PR0701

## 1. Personalización del módulo

- Creamos el controller:

    `controllers.py`
    ```python
    # -*- coding: utf-8 -*-
    from odoo import http
    from odoo.http import request


    class Taller(http.Controller):
        @http.route('/taller/static', type='http', auth='public', website=True)
        def web_estatica(self, **kw):
            return http.request.render('taller.static_web', {})

        @http.route('/taller/dinamic', type='http', auth='public', website=True)
        def web_dinamica(self, **kw):
            vehiculos = request.env['taller.vehiculo'].search([])
            return http.request.render('taller.dinamic_web', {
                'vehiculos':vehiculos
            })
    ```

- Creamos las views:
  
    `static_web.xml`
    ```xml
    <odoo>
        <template id='static_web' name='Web Taller Estática'>
            <t t-call="web.html_container">
                <div class='container'>
                    <h1>Web Estática Taller</h1>
                </div>
            </t>
        </template>
    </odoo>
    ```

    `dinamic_web.xml`
    ```xml
    <odoo>
        <template id='dinamic_web' name='Web Taller Dinámica'>
            <t t-call="web.html_container">
                <div class='container'>
                <h1>Listado de Vehículos</h1>
                    <t t-foreach="vehiculos" t-as="vehiculo">
                        <div class='vehiculo'>
                            <span><t t-esc="vehiculo.matricula"/></span>
                            <span><t t-esc="vehiculo.marca"/></span>
                            <span><t t-esc="vehiculo.modelo"/></span>
                        </div>
                    </t>
                </div>
            </t>
        </template>
    </odoo>
    ```
